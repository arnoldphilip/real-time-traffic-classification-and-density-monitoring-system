# REAL TIME TRAFFIC CLASSIFICATION AND DENSITY MONITORING SYSTEM

## Overview

The system analyzes video, camera and photo input to detect and classify vehicles, track their movement, count vehicles and estimate traffic density in a configurable Region of Interest (ROI).

## Detection classes

The YOLOv8 COCO detector supports car, motorcycle, bus and truck. A supplied fine-tuned detector can additionally identify three-wheeler / auto-rickshaw vehicles.

## Processing pipeline

```text
Video / Camera / Photo Input
        ↓
YOLO Vehicle Detection
        ↓
Vehicle Classification & Tracking
        ↓
ROI and Line-Crossing Counts
        ↓
Traffic Density Estimation (Low / Medium / High)
        ↓
Streamlit Dashboard & SQLite Database
```

## GPU acceleration

The application can use NVIDIA CUDA or Apple MPS when supported by the installed PyTorch build. CPU inference is also available. Device selection is exposed through the Streamlit sidebar.

## Configuration

- Model selection and inference confidence/resolution: Streamlit sidebar
- ROI boundaries and density thresholds: **Region of Interest (ROI) & Density**
- Compute device: **Compute & GPU Speedup**
- Counting and signal-priority behaviour: `VehicleTracker` and `TrafficSignalManager` in `unified_app.py`

## Run

```bash
python install.py
python launcher.py
```

Or:

```bash
streamlit run unified_app.py
```

## Database tables

- `TrafficDensity` — timestamp, ROI total, vehicle-type counts, density level and ROI bounds
- `VehicleCounts` — timestamped line-crossing counts by class
- `TrafficEvents` — traffic-control events generated by the application
